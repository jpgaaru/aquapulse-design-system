# AquaPulse Design System

> **Enterprise Aquaculture SaaS & IoT Telemetry Design System**  
> Calibrated for high-density sensor telemetry, cold storage allocation, hatcheries, and seafood supply chains.

## Overview
AquaPulse is an enterprise Atomic Design System built on Brad Frost's 5 Atomic Stages:
1. **Tokens**: Design variables (Palette, Typography, Elevation, Radii, Physics).
2. **Atoms**: Primitive controls (Buttons, Avatars, Badges, Switches, Skeletons).
3. **Molecules**: Compound controls (Rich Comboboxes, Searchbars, Filter Bars, Accordions).
4. **Organisms**: Complex modules (Interactive Sensor Charts, Telemetry Dual-Axis, Radial Gauge, Data Tables).
5. **Templates & Pages**: Composite executive operational dashboards.

## Color Budget & Palette
- **White Canvas (40%)**: Pure clarity (`#ffffff`, `#fafafc`).
- **Dark Structural Contrast (30%)**: Industrial black & deep slate (`#1d1d1f`, `#0d1117`).
- **Teal / Cyan Accent (30%)**: California Sunset Teal anchor (`#00a4b7` / `#006c7a`) calibrated to WCAG 2.1 AA/AAA standards.
